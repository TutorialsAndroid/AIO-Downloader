# AIO Downloader

AIO Downloads Instagram, Pinterest, Youtube, Tiktok, X, Facebook Videos and Photos. This app uses RapidAPI to download the videos and photos.

I have made this app because many apps on playstore and many websites have too much of ads and popups. So my aim is to built a ad free app.

I have only tested Instagram and Pinterest links and download works perfectly.

This App uses RapidAPI to download photos and Videos.
Sign up to RapidAPI account and get the API key.
For more info about the API go to this link and subscribe to this API : https://rapidapi.com/coder2077/api/instagram-downloader-download-instagram-videos-stories1

Important: Don't publish your API key on github use .env or local.properties file to store API Key.

Below is the Code that you have to put in local.properties file
```
RAPIDAPI_KEY=PASTE_YOUR_API_KEY_HERE
RAPIDAPI_HOST=instagram-downloader-download-instagram-videos-stories1.p.rapidapi.com
```
